# Parcours utilisateur

## Téléphone (quotidien)
1. Ouvrir l'application (icône sur l'écran d'accueil).
2. **Scanner une fiche**.
3. Taper quelques lettres du nom, un numéro de téléphone ou le n° de dossier (ex. `P-00012`).
4. Toucher le bon patient. Les homonymes affichent n° de dossier, date de naissance et téléphone pour les distinguer.
5. Patient absent : **+ Nouveau patient** → nom, prénom (le reste est facultatif). Si un nom proche existe, l'application le propose ; créer quand même demande une 2ᵉ confirmation. Jamais de fusion automatique.
6. **Prendre la première page** (appareil photo arrière), puis **Ajouter la page 2**, etc.
7. Les miniatures numérotées apparaissent dans l'ordre. Toucher une miniature : tourner, recadrer, reprendre, supprimer, avancer/reculer.
8. Date (par défaut aujourd'hui) et note facultative.
9. **Enregistrer et synchroniser** → écran d'état :
   - ⏳ *En attente* (avec « hors connexion » si pas de réseau)
   - ↑ *En cours d'envoi*
   - ✓ *Synchronisée et vérifiée* (uniquement après confirmation du serveur)
   - ! *Échec, appuyer pour réessayer*
10. **Fiche suivante**.

Chaque photo est enregistrée sur le téléphone dès sa prise : si l'application se ferme pendant la capture, l'accueil propose « Reprendre la fiche en cours ».

## Ordinateur Windows
- **Tableau de bord** : fiches du jour, patients récemment modifiés, envois incomplets, échecs de cet appareil, recherche par nom/téléphone/n° de dossier/date. Actualisation automatique toutes les 30 s.
- **Dossier patient** : identité, fiches par date (auteur, appareil, version, note, miniatures), historique des modifications.
- **Lecteur** : pages dans l'ordre, zoom (boutons, `+`/`-`, Ctrl+molette), rotation d'affichage (`R`), navigation (flèches).
- **Correction** (dentiste/admin) : « Déplacer vers un autre patient » + motif obligatoire → tracé dans les deux dossiers.
