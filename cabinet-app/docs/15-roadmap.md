# Roadmap

| Phase | Contenu | Pré-requis |
|-------|---------|------------|
| 1 (V1) | Numérisation fiable patient → photos → synchro → consultation Windows | Essai réel, validation juridique |
| 1.1 | QR code par dossier (confirmation humaine), recadrage auto, netteté, OCR assisté (image = source de vérité, texte à valider, version du moteur journalisée), recherche dans les données validées | Choix d'un OCR local ou d'un service aux garanties vérifiées (conservation, région, entraînement, suppression) |
| 2 | Dossier clinique : antécédents, pathologies (saisies/validées par le dentiste, jamais déduites d'une photo), allergies, traitements, alertes, notes, consultations, conseils validés, rappels | Modèle de données étendu (voir modèle de données) |
| 3 | Ordonnances assistées : catalogue national versionné et approuvé, favoris, champs modifiables, alertes issues d'une source fiable, PDF « Brouillon », validation explicite, versions | Source médicamenteuse officielle du Maroc ; avis réglementaire |

Règles permanentes pour l'IA : elle peut préparer un brouillon ; elle ne diagnostique pas, ne choisit pas un traitement, n'invente pas de posologie, n'émet ni ne signe ni n'envoie d'ordonnance.
